What GRID does

GRID lets anyone submit an entry directly to a configured Google Form without logging in. The private Report and Settings screens use the data owner's Google account to read the linked Sheet and synchronize GRID's own configuration.

Installing GRID

Open GRID in Chrome or another supported browser over HTTPS, then use the browser's Install app / Add to Home screen option. The PWA works as a standalone app and can use the cached shell when offline.

Data & privacy

Home sends the values you enter directly to the configured Google Form. GRID does not keep submitted entries in its own database. Report reads the linked Google Sheet only after you explicitly fetch/refresh it and Google access has been granted. GRID's local settings contain configuration, not Google login tokens.

Sharing / forking GRID

You can share the hosted GRID URL with other users. A fork/copy should use its own Google OAuth Web Client ID and its own configured Form/Sheet links. Exported JSON can transfer the GRID configuration, while each device signs into Google separately.

Legal

GRID is a client-side utility. Google Forms, Google Sheets, Google Drive and Google authentication remain Google services subject to Google's own terms and policies. The GRID operator is responsible for the forms, sheets, data and permissions configured in the app.
